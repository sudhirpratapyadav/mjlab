# Goal visualization and real-time HD refresh — 2026-09-10

Published gallery: https://cl.sudhirpratapyadav.com/v3/

The 25-task gallery now contains 45 clips at 1920×1080 and 50 fps. All 20 teachers with a measured rate strictly between 0% and 100% have both a real success and a real failure. Flip Switch, Push Flap and Reach Target measured 128/128 and have success clips only. Pivot Lift and Tool Pull measured 0/128 and have failure clips only.

Reorient Object and Topple Block now project the live object orientation onto the axis constraint with the smallest rotation. The ghost follows unconstrained horizontal motion inside the original drift region, preserves free rotation and rests on the surface at a geometry-derived height. Topple accepts either sign of its axis. The success anchor and success criteria remain unchanged. Position-only tasks retain their live-orientation ghosts. The renderer no longer adds the selected environment twice, which removes duplicate geometry and incorrect alpha blending.

Recording searches genuine episodes without rasterizing them, captures their physics and mocap states, and renders only the selected outcomes. Terminal states are captured before automatic reset. Debug overlays are disabled during playback so a previous episode's debug marker cannot contaminate a clip. Startup randomization, including friction, is resampled for each search episode. Rare outcomes are not omitted using a near-100% threshold. Axial Extract's original 128-world evaluation was reproduced exactly (127 successes, one failure); its two clips were captured from that batch and translated into the single rendering world's coordinates without resimulation.

All 29 registered classical task configurations use a 0.005 s physics timestep (200 Hz), four physics substeps per action, and a 0.02 s control interval (50 Hz). These settings were retained. Tests confirm ten control steps advance the simulation by 0.2 s at both 200 Hz/four substeps and 1000 Hz/twenty substeps. At the published 50 fps, every recorded control step produces one video frame: video duration equals the number of recorded control steps × 0.02 s, independent of wall-clock compute speed. Clips can end at task termination, timeout or shortly after success; they are not sped up to shorten them.

This establishes timing consistency, not a universal contact-accuracy guarantee for 200 Hz. MuJoCo documents timestep accuracy and stability as model-dependent: https://mujoco.readthedocs.io/en/3.8.0/computation.html . A future timestep comparison should re-evaluate teachers and contact behavior while preserving 50 Hz control.

The prior strict 128-trial teacher rates are retained with source provenance in each result.json; this visual refresh does not claim improved teacher accuracy. Axial Extract additionally reproduced its measured batch. The preceding low-resolution gallery is archived at https://cl.sudhirpratapyadav.com/v3_before_hd_20260910/ .

Validation: 80 focused tests pass, covering axis projection, live ghost behavior, recorded-state coordinate translation, duplicate scene prevention, frame timing, configuration rates, actual simulation clock advancement, episode evaluation and teacher geometry. New recording/goal modules and their tests pass Ruff. Final video checks count decoded frames, check resolution/fps/duration, and require both outcomes for every intermediate success rate. Publication checks decode every clip and compare HTTPS video/image hashes and result metadata with local artifacts, including checks that obsolete clips return 404.
